External boundaries

Firmware compatibility formats

Link Studio lists every resolution and rate advertised by active firmware. It does not send unidentified writes to unlock firmware-only compatibility modes. The tested Link 2 advertises 24, 25, and 30 fps through 4K.

Hardware-only orientation

Vertical flip and portrait rotations are supplied in the complete processed output path. Unknown persistent hardware correction bits are not written.

Firmware flashing and reset

The current firmware and build are read directly from the camera. Updates open Insta360's recovery-safe U-Disk instructions; Link Studio never writes an unauthenticated firmware blob over an inferred protocol.

Vendor accounts and cloud

Identity, membership, billing, and InSight cloud services cannot be cloned. Link Studio supplies account-free local recording, offline transcription, markers, and summaries.

Wayland stacking

The teleprompter is a dedicated window. Hyprland and Wayland retain final authority over whether any surface stays above every other application.

Safe camera shutdown

Link Studio closes the window immediately, then drains its non-daemon camera worker before closing the device descriptor. This prevents descriptor reuse while an ioctl is in flight. If a kernel driver leaves an ioctl permanently wedged, the process can remain alive without a window until that kernel call returns.

Privacy and security

  • Camera frames used by effects remain on the machine.
  • The phone remote is disabled by default, LAN-only, and protected with a random per-session token.
  • Support bundles exclude screenshots and recordings.
  • Unknown or destructive UVC extension writes are excluded.
  • Global actions use the desktop portal instead of editing compositor configuration.
