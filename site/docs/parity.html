Feature parity

Link Studio implements the safe Linux application scope: direct controls validated on hardware and local equivalents that produce the same usable output without guessing destructive protocols.

Safety boundaries

Firmware compatibility formats

Original Link (2e1a:4c01) has an explicit Device → Portrait resolutions and high frame rates toggle, verified on firmware v1.4.5.8_build1. Stop preview, recording and virtual output, and close other camera clients first: the camera may restart. Startup, scenes and phone remote never apply this setting. Successful verification refreshes advertised formats and retains a still-valid resolution/rate, without forcing 60 fps.

The protocol uses XU 9, selector 27, a strictly checked two-byte little-endian feature word and bit 5 (0x0020). All other bits, including separate portrait lock bit 10, are preserved. Unchanged states are not written; full-word readback is required. After initial verification, Link Studio closes the old descriptor, waits eight seconds for firmware restart, then polls for up to 24 seconds for the same model and USB physical port. It reopens the camera, clears cached lengths and checks the opened descriptor's port. Success requires both 720p and 1080p to show 60 fps when enabled (neither when disabled), plus feature-bit readback on the reopened descriptor. Preview stays blocked until recovery finishes, and uses the new video-node path if it changed. Empty/stale formats and transient reopen errors are retried, never the setting write. If verification or recovery fails, preview remains blocked until you reconnect the camera and reopen Link Studio; the application does not claim success. A missing physical-port identity is rejected before writing.

Provenance: analysis of the official Controller 2.0.3 (build 2) traced EnableVerticalScreen to EnableExtendFuncWork with bit index 5. Original-Link native capture confirmed 602 frames over 10.02 seconds; a separate 180-frame/3-second framehash sample contained 179 unique frames and one adjacent duplicate. No firmware was flashed; unplug/reboot persistence and other firmware are untested.

Link 2 remains unverified for this toggle and is not offered it. Link Studio lists its advertised formats; the tested Link 2 firmware advertises 24, 25, and 30 fps through 4K. Compatibility writes are never guessed for other models.

Hardware-only orientation

Vertical flip and portrait rotations are supplied in the processed output path. Unknown persistent hardware-correction bits are not written.

Firmware flashing and reset

The current firmware and build are read directly from the camera. Updates open Insta360's recovery-safe U-Disk instructions; Link Studio does not write a firmware image through an inferred protocol.

Vendor accounts and cloud services

Identity, membership, billing, and InSight services are outside the application scope. Link Studio supplies account-free local recording, offline transcription, markers, and summaries.

Wayland window stacking

The teleprompter is a dedicated window. The active Wayland compositor retains final authority over whether any surface remains above every other application.

Camera worker shutdown

The window closes immediately, then a non-daemon drain thread waits for the camera worker before closing the device descriptor. This prevents descriptor reuse while an ioctl is in flight. If a kernel driver leaves an ioctl permanently wedged, the process can remain alive without a window until that call returns.

Privacy and security

  • Camera frames used by effects remain on the machine.
  • The phone remote is disabled by default, LAN-only, and protected by a random per-session token.
  • Support bundles exclude screenshots and recordings.
  • Unknown or destructive UVC extension writes are excluded.
  • Global actions use the XDG desktop portal instead of editing compositor configuration.

Reporting an issue

Open an issue in the GitHub repository and attach the support bundle exported from Device → Application. Include the camera model, firmware version, selected video format, and the action that led to the problem.
