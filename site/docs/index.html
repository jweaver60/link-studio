Getting started

Quick start

Connect the webcam, launch Link Studio, and start a preview. The application selects the first compatible device and a supported video mode automatically.

Launch the application

Open Link Studio from the desktop application menu, or start it from a terminal:

link-studio

If multiple video devices are present, use the device selector in the preview toolbar. Link Studio only offers formats reported by the selected device.

Start preview

  1. Connect the Link webcam directly over USB.
  2. Select a resolution and frame rate in the preview toolbar.
  3. Turn on Preview.

The default is 1280 × 720 at 30 fps when that mode is advertised. Changing resolution or orientation safely stops active recording and virtual-camera output before rebuilding the stream.

Only one capture client at a time

Many webcams cannot provide the same V4L2 stream to two applications simultaneously. Stop preview before opening the physical camera directly in another program, or use Link Studio's processed virtual camera.

Capture a frame or recording

Use the camera button for a PNG screenshot and the record button for an H.264/AAC MP4. The Device page shows and changes the output folders. Recording uses the selected PipeWire microphone source.

For OBS, browsers, or meeting software, install the optional virtual-camera helper and enable Virtual camera on the Effects page. Processed frames then appear at /dev/video20.

Check a problem

The command-line diagnostic is read-only and reports device discovery, video formats, firmware information, and the available audio/video stack:

link-studio --diagnose

For an issue report, export a support bundle from the Device page. Bundles exclude camera frames, screenshots, and recordings.
