Get started

Install on
Omarchy or Arch.

Link Studio installs for one user without changing Hyprland or Omarchy configuration. Optional helpers add a virtual camera and offline transcription only when requested.

Private preview

The AUR recipe is complete and tested locally, but AUR publication waits for a publicly downloadable source release. The GitHub repository remains private for now.

AUR launch

Once the upstream source release is public, install the stable package with your preferred AUR helper:

yay -S link-studio

The package depends on the normal Arch GTK, GStreamer, PipeWire, OpenCV, and Python stack plus python-mediapipe from the AUR.

Private source install

Repository collaborators can clone over SSH and run the user installer:

git clone git@github.com:jweaver60/link-studio.git cd link-studio ./scripts/install-user

The installer anchors its environment to /usr/bin/python, preserving Omarchy's system GTK bindings while installing Link Studio's Python dependencies.

Native requirements

sudo pacman -S gtk4 libadwaita python-gobject gstreamer \ gst-plugins-base gst-plugins-good gst-plugins-bad gst-libav v4l-utils

Optional integrations

Processed virtual camera

Creates a temporary /dev/video20 through v4l2loopback. The helper uses Omarchy's package command and does not write persistent kernel configuration.

link-studio-setup-virtual-camera

Offline transcription

Installs whisper.cpp and downloads the multilingual base model. The 142 MiB model is verified against a pinned SHA-256 digest before use.

link-studio-setup-local-ai

Verify the camera

link-studio --version link-studio --diagnose

Diagnostics are read-only. They report detected devices, advertised formats, firmware/build information, current safe control state, and the active Omarchy palette.
